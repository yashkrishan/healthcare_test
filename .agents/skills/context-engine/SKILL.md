# Context Engine Router

Use this skill when the shallow memory brief is not enough.

1. Pick the route:
   - Repo purpose / baseline -> `potpie-repo-baseline`
   - Recent changes / regressions -> `potpie-change-timeline`
   - Infra / environments / adapters -> `potpie-infra-architecture`
   - Graph reads / entity lookup -> `potpie-graph`
   - Debugging / prior bugs -> `potpie-debug-memory`
   - Coding preferences / conventions -> `potpie-project-preferences`
2. Run the matching `potpie ...` commands in shell.
3. Use results as constraints before answering.
